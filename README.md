# Dungeon Heart — Trap Defense

Полный 10-волновый прототип по `PROTOTYPE_GAME_DESIGN.md`: React управляет экранами и HUD, PixiJS — полем, толпой, raster-ассетами и VFX. Реализованы пять архетипов стейджа, десять ловушек, пять ролей врагов, шесть реакций, четыре цепочки перков, развитие Dungeon Heart и подробная статистика результата.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173/`. Игра всегда сохраняет пропорцию 9:16; мышь повторяет touch-ввод.

## Управление

- В подготовке перетащите карточку магазина прямо на поле. Во время жеста валидные origins отмечаются зелёным, а footprint фигуры подсвечивается зелёным или красным.
- `Копать` и `Стена` включают взаимоисключающие режимы изменения карты.
- Тап по установленной ловушке открывает перемещение, улучшение и продажу. В режиме перемещения можно бесплатно перетаскивать все ловушки до подтверждения галочкой. Тап по Dungeon Heart открывает улучшение и ремонт.
- В бою доступны пауза и скорость ×1/×2.
- Клавиша `D` показывает/скрывает debug overlay симуляции; `S` при открытом overlay запускает локальный QA stress-сценарий на 300 активных врагов.

## Проверки

```bash
npm test
npm run build
```

15 unit/property-проверок покрывают детерминизм и связность генератора, длину и извилистость маршрутов, предел открытого пространства, архетипические диапазоны террейна, пять архетипов, отсутствие изолированных проходов, кривые количества и прочности 10 волн, каталог ловушек, экономику фигур, ограничения магазина, перки и все шесть реакций. Дополнительно используется 300-unit stress-сценарий в целевом viewport 9:16.
